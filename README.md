# WGKMS – Corrected Desktop Build

This package preserves the desktop Stitch screens and includes targeted fixes for the Philippine map asset, role switching, and volunteer scheduling calendar.

## Publish with GitHub Pages
1. Upload the contents of this folder to the repository root.
2. In GitHub, open Settings → Pages.
3. Select Deploy from a branch, branch `main`, folder `/ (root)`.
4. Save.

## Main pages
- `index.html` – Home dashboard
- `volunteers.html` – Volunteer management
- `volunteer-assignments.html` – Interactive volunteer duty calendar
- `volunteer-portal.html` – Volunteer portal
- `donations.html` – Donations
- `data-dashboard.html` – Data dashboard
- `inventory.html` – Inventory

The Admin/Guest switch is a frontend demonstration only; it is not secure authentication. Shared multi-user data requires a backend and server-side authorization.
